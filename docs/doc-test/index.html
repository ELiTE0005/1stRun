Doc-test

FirstRun runs a docs quickstart in a clean container. When a step breaks, it fixes the step and proves the fix in a second clean run.

A docs URL shows its saved result or the command to test it. A share code opens the replay. Nothing leaves your browser. Agents can read agent.md.

Watch the 3 minute demo, 2:59DocTest on YouTube

    FirstRun stopped on these pages before it proved a fix. A stop can come from the docs, the container, or a step that needs a login or a browser, so these runs make no claim that the docs are wrong.
